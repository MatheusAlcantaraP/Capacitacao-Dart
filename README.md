# 📚 Sistema de Gestão Bibliotecária

Projeto desenvolvido em Dart para simular o funcionamento de uma biblioteca comunitária.  
O sistema permite gerenciar livros e revistas, realizar empréstimos, devoluções e controlar o estoque da biblioteca.

---

# 🎯 Objetivo

Desenvolver um sistema capaz de:

- Cadastrar clientes;
- Gerenciar o acervo da biblioteca;
- Realizar empréstimos e devoluções;
- Controlar estoque dos itens;
- Calcular valor total da devolução.

---

# 📋 Requisitos Funcionais

## RF01 — Cadastro de Clientes
O sistema deve permitir cadastrar clientes da biblioteca.

## RF02 — Cadastro de Itens
O sistema deve permitir cadastrar livros e revistas no acervo.

## RF03 — Empréstimo de Itens
O sistema deve permitir emprestar itens disponíveis no estoque.

## RF04 — Devolução de Itens
O sistema deve permitir devolver itens e calcular o valor total da devolução.

## RF05 — Listagem de Estoque
O sistema deve listar todos os itens disponíveis na biblioteca.
